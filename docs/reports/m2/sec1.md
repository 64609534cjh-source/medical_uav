`medical_uav/agents/networks.py` contains both networks. Each takes a batch of observations [B, 452] and action masks [B, 26] and returns action logits [B, 26] and state values [B]. Logits of forbidden actions are replaced by −10⁹, so the policy never picks them and no policy gradient flows through them. `split_obs` splits each observation into a global part (80 features), 12 waiting-order slots (27 each) and 3 cargo slots (16 each).

Waiting orders form a set: the slot an order fills should not change the decision. The set network (Figure 1), our proposal's design, therefore encodes every order slot and every cargo slot with shared encoders, and the global state separately. In four-head attention the UAV encoding queries the orders, the cargo and a learned null token, ignoring empty slots (the null token keeps attention defined when all are empty); the attention output joined with the UAV encoding is a 128-feature context. A shared scorer turns each order's encoding and the context into its PICK logit, so reordering the slots only reorders the PICK logits; a second head scores the 14 other actions, and the value head uses the context and the mean order encoding. The network has 62,928 parameters. To test whether this structure is worth it, a plain MLP control has a separate actor and critic (452 → 256 → 256, tanh; 370,459 parameters). `policy.py` picks the allowed action with the highest score and saves and loads checkpoints.
