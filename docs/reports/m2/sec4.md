**Network demo.** `python scripts/demo_network.py` builds both networks and prints their sizes, runs a **forward pass** of the trained set network on 64 observations from a simulated day (logits [64, 26], values [64]) next to Slack-aware's choices, then a **backward pass** on a fresh network (policy loss: cross-entropy to Slack-aware's actions; value loss: squared error to the scaled reward still to come) and one Adam step, after which the loss is lower.

**Replay.** M1's animation ran too fast to follow, so M2 replaces it: `scripts/demo.py` saves an offline web page replaying the day decision by decision (play, pause, step, 1–3× speed), pausing about 2 s at each decision to show the situation and the top three actions; `--video` also saves the busiest stretch as an MP4. (Pauses are for the reader.)
