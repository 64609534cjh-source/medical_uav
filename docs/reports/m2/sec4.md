After the README setup, `python scripts/demo_network.py` prints both networks' sizes, runs the trained set network on 64 real observations (logits [64, 26], values [64]) and compares three of its decisions with Slack-aware's. A fresh set network then shows backpropagation of the policy and value losses and one Adam update (the loss falls); finally both trained networks dispatch a whole day.

The M1 GIF was too fast to follow, so `scripts/demo.py --policy set` now writes the whole day as a replay web page: a single file that opens offline in any browser, where the reader plays, pauses, steps from decision to decision or drags a timeline. Each decision is shown in words with the situation it was taken in and up to three of the network's most likely actions (Figure 2). At each decision playback stops for about 2 s while the chosen action moves from the list of choices into place; the pause is for the reader, as the network decides in about 1 ms. `assets/` holds the replay of one unseen day for the network and for Slack-aware.
