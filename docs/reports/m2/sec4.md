`python scripts/demo_network.py` shows the networks at work. It prints their sizes, runs the trained set network on 64 real observations (logits [64, 26], values [64]) and compares three of its decisions with Slack-aware's. A fresh set network then backpropagates its losses and takes one Adam step (the loss falls), and finally both trained networks run a whole day.

The M1 animation was too fast to follow, so we rebuilt the visualization around decisions. `python scripts/demo.py --policy set --seed 100000` saves an offline replay that can be played, paused and stepped decision by decision. At 1× it pauses for about 2 s at each decision to show the situation and up to three action probabilities (Figure 2); decisions are computed before playback, so the pause is only for the reader. `assets/` holds this replay, Slack-aware's on the same day and a 2 min 50 s video of the afternoon backlog.
